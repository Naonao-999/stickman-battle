# 🔥 火柴人大战（Stickman Battle）

一个纯 HTML/CSS/JavaScript 编写的双人火柴人格斗小游戏，零依赖、单文件即可运行。

## 在线试玩

开启 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何环境。

## 操作说明

| 动作 | 玩家 1（红色） | 玩家 2（蓝色） |
| ---- | ---- | ---- |
| 移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W` | `↑` |
| 防御 | `S` | `↓` |
| 拳击 | `F` | `J` |
| 踢击 | `G` | `K` |

- `空格` / `回车`：开始游戏、重新开始
- `M`：静音 / 取消静音

## 玩法规则

- 双人对战，**三局两胜**，率先赢下 2 回合者获胜。
- 每回合 60 秒，时间耗尽时血量高的一方获胜（平局则重赛）。
- 拳击速度快、伤害低；踢击距离远、伤害高、带击退。
- 按住防御键可大幅减免伤害（无法在出招时防御）。

## 技术实现

- Canvas 2D 实时渲染，火柴人由两段式四肢（前向运动学）+ 姿态插值驱动动画。
- 使用 WebAudio 实时合成音效，无需任何外部音频文件。
- 粒子火花、屏幕震动、血量/回合/倒计时等完整的格斗反馈。
